# Futterbuch

Ernährungstagebuch als installierbare Web-App (PWA): Tagesplan (Soll) und Gegessenes (Ist), Mengen jederzeit änderbar, Barcode-Scan, Suche in Open Food Facts, Gewicht. Funktioniert offline.

Die Daten liegen nicht hier, sondern in einem privaten Repo (Standard: `antonettylukas/futterbuch-daten`). Die App gleicht sie mit einem Fine-grained Token ab, der nur auf dieses Repo Zugriff hat (Contents: Read and write). Der Token bleibt auf dem Gerät.

Installieren: Seite in Chrome auf dem Handy öffnen → Menü → „Zum Startbildschirm hinzufügen“ bzw. „App installieren“.
